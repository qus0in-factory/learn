# 버전 관리의 세 영역
교안: [STEP 01 §학습 목표](https://echo.qus0in.dev/git/01-environment#학습-목표)

- 변경 이력을 남기는 이유를 살펴본다.
- Git의 세 영역과 상태 흐름을 이해한다.
- 터미널과 실습 환경을 확인한다.

## 버전 관리가 필요한 이유
교안: [STEP 01 §왜 버전·형상 관리를 할까](https://echo.qus0in.dev/git/01-environment#왜-버전·형상-관리를-할까)

- 복사본이 많아지면 최신 상태와 변경 이유를 찾기 어렵다.
- 버전 관리는 변경 이력을 기록하고 이전 상태를 찾는 데 도움을 준다.
- 형상 관리는 프로젝트 구성 요소를 하나의 상태로 묶어 관리한다.

## Git의 세 영역
교안: [STEP 01 §로컬 3단계 구조와 상태 변화](https://echo.qus0in.dev/git/01-environment#로컬-3단계-구조와-상태-변화)

- 작업 공간에서 파일을 만들고 수정한다.
- 스테이징 영역에서 다음 기록에 포함할 변경을 고른다.
- 로컬 저장소에 선택한 상태를 커밋으로 기록한다.

## 환경 확인 순서
교안: [STEP 01 §따라하기](https://echo.qus0in.dev/git/01-environment#따라하기)

- VS Code에서 통합 터미널을 연다.
- 운영체제에 맞는 셸과 Git 설치 상태를 확인한다.
- 현재 작업 위치와 OpenCode 응답을 확인한다.

## 준비 완료 기준
교안: [STEP 01 §체크리스트](https://echo.qus0in.dev/git/01-environment#체크리스트)

- Git 버전과 현재 작업 경로를 확인한다.
- 세 영역의 역할과 흐름을 설명한다.
- OpenCode에서 정상 응답을 확인한다.

## 안전한 실습
교안: [STEP 01 §주의할 점](https://echo.qus0in.dev/git/01-environment#주의할-점)

- 실습 전용 폴더에서 작업한다.
- 터미널과 대화창에 비밀번호나 토큰을 입력하지 않는다.
- 환경 문제가 생기면 교안의 해결 안내를 확인한다.
