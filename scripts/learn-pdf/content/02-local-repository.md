# 저장소 준비와 파일 추적
교안: [STEP 02 §학습 목표](https://echo.qus0in.dev/git/02-local-repository#학습-목표)

- 커밋에 기록할 작업자 정보를 준비한다.
- 실습 폴더를 로컬 저장소로 초기화한다.
- 파일 상태를 확인하고 기록할 변경을 선택한다.

## 작업자와 저장소
교안: [STEP 02 §작업자 등록과 저장소 초기화](https://echo.qus0in.dev/git/02-local-repository#작업자-등록과-저장소-초기화)

- 작업자 이름과 이메일은 커밋의 작성자 정보로 기록된다.
- 실습 전용 폴더로 이동해 저장소를 초기화한다.
- 생성된 숨김 폴더에 저장소 이력이 보관된다.

## 파일 상태의 흐름
교안: [STEP 02 §파일 상태와 스테이징 원리](https://echo.qus0in.dev/git/02-local-repository#파일-상태와-스테이징-원리)

- 새 파일은 처음에 미추적 상태다.
- 추적 파일을 수정하면 변경된 상태로 나타난다.
- 기록할 변경을 스테이징하고 커밋으로 남긴다.

## 첫 웹페이지 만들기
교안: [STEP 02 §예시 산출물](https://echo.qus0in.dev/git/02-local-repository#예시-산출물)

- OpenCode에 첫 웹페이지 생성을 요청한다.
- 첫 단계에서는 HTML5만 사용한다.
- CSS·JavaScript·외부 라이브러리는 제외하고 결과를 확인한다.

## 빈 폴더 기록
교안: [STEP 02 §빈 폴더와 `.gitkeep`](https://echo.qus0in.dev/git/02-local-repository#빈-폴더와-gitkeep)

- Git은 빈 폴더 자체를 추적하지 않는다.
- 폴더 안에 파일을 두면 파일과 함께 폴더가 기록된다.
- 빈 파일의 이름은 관례이며 특별한 Git 기능이 아니다.

## 변경 선택 순서
교안: [STEP 02 §따라하기](https://echo.qus0in.dev/git/02-local-repository#따라하기)

- 파일을 저장하고 미추적 상태를 확인한다.
- 기록할 파일을 골라 스테이징한다.
- 상태를 다시 확인해 선택한 파일이 준비되었는지 살펴본다.

## 완료와 주의
교안: [STEP 02 §체크리스트](https://echo.qus0in.dev/git/02-local-repository#체크리스트)

- 작업자 정보와 저장소 초기화를 확인한다.
- 선택한 파일이 스테이징되었는지 확인한다.
- 민감한 파일이 포함되지 않도록 변경을 확인한다.
