# 개인정보처리방침(초안)

이 문서는 운영자 검토 전 초안이며 법률 자문이나 확정된 운영 방침을 대신하지 않는다. 광고·분석을 활성화하기 전에 실제 처리 항목, 법적 근거, 동의 방식, 제공자, 보관 기간, 문의처를 확인해 확정한다.

## 현재 동작

- 광고와 Google Analytics는 기본적으로 꺼져 있다. 측정 ID가 없으면 분석 스크립트를 출력하지 않는다.
- 내장 검색은 브라우저에서 처리한다. 화면 테마·검색 UI 등 편의 설정이 브라우저 저장소에 남을 수 있다.
- 사이트와 정적 파일을 제공하는 호스팅 사업자는 서비스 제공·보안 목적으로 IP 주소, 브라우저 정보, 접속 시각 같은 요청 정보를 처리할 수 있다. 실제 보관 기간과 처리 지역은 해당 사업자의 설정·약관을 확인한다.
- 카카오·X 공유나 외부 링크를 이용하면 외부 서비스의 방침이 적용될 수 있다. API 키·비밀번호 같은 비밀정보를 이 사이트에 입력하지 않는다.

## 광고를 켤 때

- 직접 업로드한 배너는 광고 표시와 후원 링크를 함께 제공한다. 외부 광고 SDK나 개인화 추적은 기본 슬롯에 포함하지 않는다.
- 광고 공급자를 추가하기 전에 쿠키·기기 식별자·제3자 전송 여부와 동의·거부 방법을 검토한다.
- 배너 이미지·연결 주소·게시 기간은 운영 설정으로 관리한다.

## 분석을 켤 때

- GA4를 켜기 전에 수집 이벤트, 식별자, 전송 대상, 보관 기간, 필요한 동의 절차를 검토한다. 초안 공개만으로 분석을 활성화하지 않는다.
- 개인 식별 정보·비밀번호·토큰을 이벤트나 URL에 포함하지 않는다.
- 분석·광고 설정은 언제든 비활성화할 수 있다. 외부 서비스에 이미 수집된 정보의 삭제·권리 행사는 해당 서비스와 운영자의 확정 절차를 따른다.

## 확정 전 확인

- 운영자명·개인정보 문의처·시행일을 기재한다.
- 수집 항목·목적·근거·보관 기간과 제3자 제공·국외 이전 여부를 확인한다.
- 동의 철회·열람·정정·삭제 요청 절차와 아동·청소년 관련 의무를 확인한다.
- 실제 활성화 설정과 이 문서가 일치하는지 점검한다.
