# 개인정보처리방침

이 방침은 운영자 변영인이 제공하는 Echo 학습 사이트의 개인정보 처리와 문의 방법을 안내한다. 별도 회원가입 기능은 없다.

이 문서는 공개 준비 중이며 실제 배포 환경의 로그와 외부 서비스 설정을 확인한 뒤 시행일을 정한다. 아래 설명은 현재 소스와 확인된 운영 계획을 기준으로 하며, 실제 처리 항목과 보관 기간은 운영 환경 확인 후 보완한다.

## 사이트 접속과 제공

사이트는 Cloudflare의 정적 파일, Worker, 데이터베이스와 파일 저장 서비스를 사용해 페이지와 강의 자료를 제공한다. 접속 요청은 Cloudflare에 전달되며, 서비스 제공과 보안 과정에서 IP 주소, 요청 주소, 접속 시각, 브라우저 정보 등이 처리될 수 있다. 확인한 사이트 코드에서는 방문자 정보를 강의 카탈로그 데이터베이스에 기록하거나 요청을 직접 기록하는 기능을 발견하지 못했다. 이것만으로 Cloudflare의 로그나 보안 처리가 없다는 뜻은 아니다.

실제 로그의 항목과 보관·삭제 기간, 처리 지역과 Cloudflare의 계약 관계 및 국외 이전 해당 여부는 운영 설정을 확인한 뒤 안내한다. 비밀번호, 인증 토큰 등 민감한 정보는 주소나 검색어에 넣지 않는다.

## 검색과 브라우저 저장

사이트 내 검색은 브라우저에서 처리한다. 테마와 검색 화면 등은 브라우저 저장소를 사용할 수 있으며, 외부 서비스나 보안 기능도 쿠키 등을 사용할 수 있다. 실제 저장 항목은 배포 환경에서 확인해야 한다.

브라우저 설정에서 사이트 데이터와 쿠키를 확인하거나 삭제하고 저장을 제한할 수 있다. 제한하면 일부 편의 기능이나 외부 기능이 정상적으로 동작하지 않을 수 있다. 이러한 설정이 사이트 접속에 필요한 네트워크 요청까지 막는 것은 아니다.

## 공유와 외부 서비스

카카오 공유 기능은 설정에 공개 JavaScript 키가 있으면 공유 버튼을 누르기 전에도 카카오 SDK를 불러올 수 있다. 이때 브라우저가 카카오 서버에 접속하면서 IP 주소 등 네트워크 정보가 전달될 수 있다. 공유할 때는 페이지 제목, 설명, 주소와 이미지 정보가 전달된다. 카카오의 처리에 관한 내용은 [카카오 개인정보처리방침](https://privacy.kakao.com/policy?lang=ko)을 참고한다.

X 공유나 다른 외부 링크를 열면 해당 서비스의 방침이 적용될 수 있다. 정적 파일이나 PDF를 제공하는 외부 주소에 접속할 때에도 해당 서버에 요청 정보가 전달될 수 있다. 실제 사용 중인 주소와 제공자 관계는 배포 설정을 확인한 뒤 보완한다.

## 분석과 광고

현재 저장소 설정에서 Google Analytics와 외부 광고는 활성화되어 있지 않다. 이는 소스 설정을 확인한 결과이며 실제 배포 환경이나 외부 계정 전체를 확인한 것은 아니다.

운영자는 향후 Google Analytics 4와 Search Console을 도입하고 카카오 AdFit과 Google AdSense 광고를 검토할 계획이다. Search Console은 검색 성능과 사이트 관리 도구이며 그 자체를 방문자 추적용 Analytics 쿠키와 동일하게 취급하지 않는다. 분석이나 광고를 활성화하기 전 실제 수집 항목, 쿠키, 제공자, 보관 기간, 필요한 동의와 거부 방법을 확인하고 이 방침을 갱신한다.

## 문의와 권리 행사

개인정보 열람, 정정, 삭제, 처리 정지 등 권리 행사와 개인정보 관련 문의는 운영자 변영인에게 [qus0in@gmail.com](mailto:qus0in@gmail.com)으로 보낼 수 있다. 요청 내용과 회신에 필요한 연락처를 알려 주되 비밀번호나 인증 토큰은 보내지 않는다. 법령상 요건이나 다른 사람의 권리에 따라 요청 처리가 제한될 수 있다.

문의 메일의 실제 보관·삭제 기준과 처리 절차는 운영 환경을 확인한 뒤 보완한다.

## 시행과 변경

시행일은 실제 공개 배포 전에 결정한다. 처리 내용이 바뀌면 변경 내용을 확인해 이 방침에 반영한다.
