# git tag

## 용도

커밋 하나에 `v0.1.0` 같은 이름표를 붙여 나중에 찾기 쉽게 한다. 이름만 붙이는 경량 태그와, 작성자와 설명을 함께 기록하는 주석 태그가 있다. 포트폴리오를 공개하거나 과제를 제출한 시점을 표시할 때 쓴다.

## 자주 쓰는 옵션

| 옵션 | 의미 | 기본 동작 |
| --- | --- | --- |
| (없음) | 태그 목록 출력 | 이름순 |
| `이름` | 현재 커밋에 경량 태그 | 설명 없음 |
| `-a 이름 -m "메시지"` | 작성자·날짜·설명이 있는 주석 태그 | 공개 버전에 권장 |

## 예시

```bash
git tag -a v0.1.0 -m "Release v0.1.0"
git tag
git tag temp-mark
```

`git tag`에 `v0.1.0`이 보이면 주석 태그가 붙은 것이다. `temp-mark`처럼 이름만 붙이는 경량 태그는 임시 표시에 쓴다.

## 주의할 점

- 태그는 현재 커밋에 붙는다. 붙이기 전에 `git log --oneline`으로 원하는 커밋인지 확인한다.
- 같은 이름의 태그는 두 번 만들 수 없다. 버전 번호를 올려 새로 만든다.
- 태그는 `git push`만으로는 원격에 올라가지 않는다. 원격 공유는 강사 안내에 따라 진행한다.
