# ChatGPT로 기록 고도화

ChatGPT는 GitHub 계정을 연결(커넥터)해 저장소의 파일과 문서를 읽고 질문에 답하게 할 수 있다. 예전의 플러그인 방식이 아니라 연결 기능을 기준으로 설명한다. 요금제와 계정 종류에 따라 쓸 수 있는 기능이 다를 수 있다. 화면과 메뉴 이름은 버전에 따라 다를 수 있다. 정확한 절차는 [OpenAI 도움말 센터](https://help.openai.com)에서 "ChatGPT 커넥터"를 검색해 확인한다.

## 연결

1. ChatGPT 설정에서 앱·커넥터 연결 항목을 찾아 GitHub를 선택한다.
2. GitHub 로그인 화면이 나오면 로그인하고, ChatGPT가 접근할 계정이나 저장소를 고른다.
3. 앞 페이지에서 만든 실습 저장소와 Profile 저장소만 연결한다. 비공개 저장소는 꼭 필요한 것만 연다.
4. 필요 없어지면 같은 설정 화면이나 GitHub 설정에서 연결을 해제한다.

비밀정보, 토큰, 비밀번호가 든 파일은 접근시키지 않는다. 생성된 문장에 그런 값이 있으면 커밋하지 않고 지운다.

## 수정과 리뷰

연결한 뒤 대화에서 파일을 지정해 요청한다. 초안을 그대로 커밋하지 않고, 사실과 다른 문장·확인하지 않은 메뉴 이름·과장된 성과를 지운 뒤에 웹 편집기에서 커밋한다.

1. Profile 저장소 README를 읽고, 소개와 관심 기술이 한 화면에서 보이는지 짧게 다듬게 한다. 다른 사람 문장을 통째로 붙이지 않는다.
2. `docs/til.md`를 Why→What→How로 다시 배열하게 한다. 이유, 배운 내용, 적용 방법을 나누고, 직접 확인하지 않은 결과는 확인 전이라고 남긴다.
3. `docs/retrospective.md`의 Try가 실행 시점과 확인 방법을 갖는지 리뷰하게 한다.
4. `docs/postmortem.md`를 STAR(상황, 과제, 행동, 결과)로 읽어 보게 한 뒤, 확인된 원인과 추측이 섞이지 않았는지 고친다. 재발 방지책이 없으면 추가한다.
5. 고친 뒤 저장소 화면에서 README와 기록 파일이 렌더링되는지 확인하고, 관련 이슈에 리뷰한 사실을 한 줄 남긴다.

요청 예: "내 저장소의 README와 docs/til.md를 읽고, 확인하지 않은 사실은 단정하지 말고 고칠 문장만 제안해 줘."
