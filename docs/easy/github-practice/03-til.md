TIL은 오늘 배운 내용 중 다시 참고할 점을 짧게 남기는 기록이다. 명령어만 복사하기보다 언제 쓰고 무엇을 확인했는지 적으면 복습에 도움이 된다. 날짜나 주제별 파일에 배운 점과 직접 확인한 결과를 적는다.

- 해결하려던 질문과 배운 내용
- 실행한 명령 또는 참고 링크
- 확인 결과와 남은 질문
