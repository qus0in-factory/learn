## 목표

`.md`의 제목·목록·링크·코드 문법을 익히고 README와 GitHub Profile을 작성합니다. Issue·Label·Milestone·TIL·회고·부검·Wiki를 소개하고 `gh`와 ChatGPT GitHub 연결은 선택 기능으로 확인합니다.

## 3시간 진행

- 1교시: Markdown 문법으로 짧은 소개 작성
- 2교시: README에 자기소개와 Pages 링크 추가, 미리보기 확인
- 3교시: Issue에 개선점 작성, Label·Milestone·Wiki·TIL 소개

각 교시는 45분 수업과 15분 휴식입니다. 세 번째 수업의 마지막 20분은 아래 과제 15분과 퀴즈 5분으로 둡니다. 설치나 인증이 막히면 강사 시연과 예제 저장소로 이어가며 자기 변경을 확인하게 합니다.

## 실습 과제

README에 소개와 배포 링크를 넣고, Issue 하나에 다음 개선점을 기록한 뒤 커밋합니다.
