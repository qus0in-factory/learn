## 목표

Git·GitHub, VCS/SCM, Working Directory·Staging Area·Repository를 구분합니다. VS Code, Git for Windows/Git Bash와 코딩 에이전트 설치를 시작하고 Git 사용자 설정을 합니다. `.gitkeep`과 `.gitignore`의 역할도 살펴봅니다.

## 3시간 진행

- 1교시: 도구 설치·확인, Git과 GitHub 차이, 세 영역 설명
- 2교시: 에이전트에 작은 제목 변경 요청, 브라우저와 diff 확인
- 3교시: `init`·`status`·`add`·`commit`·`log --oneline` 실습

각 교시는 45분 수업과 15분 휴식입니다. 세 번째 수업의 마지막 20분은 아래 과제 15분과 퀴즈 5분으로 둡니다. 설치나 인증이 막히면 강사 시연과 예제 저장소로 이어가며 자기 변경을 확인하게 합니다.

## 실습 과제

제목을 자기 소개 문구로 바꾸고 파일을 선택해 커밋합니다.
