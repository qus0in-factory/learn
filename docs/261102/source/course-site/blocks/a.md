# A · 시작과 첫 기록

[전체 블록 안내](../) · <a href="/git/slides/11">이 블록의 슬라이드</a>

## 목표

Git과 GitHub의 역할을 구분하고, 프로젝트 폴더에서 첫 변경을 로컬 기록으로 남깁니다.

## 3시간 진행

- 1교시: Git·GitHub·작업 폴더와 스테이징을 살펴보고 설치 상태를 확인합니다.
- 2교시: 에이전트에게 작은 문구 변경을 요청하고 브라우저와 변경 내용을 확인합니다.
- 3교시: `git init`, `git status`, `git add`, `git commit`을 한 줄씩 실행합니다.

각 교시는 45분 수업과 15분 휴식으로 진행합니다. 설치나 인증이 막히면 준비·질문 시간을 쓰고, 준비된 학습자는 실습을 이어갑니다.
