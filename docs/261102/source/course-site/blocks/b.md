# B · GitHub에 공유

[전체 블록 안내](../) · <a href="/git/slides/12">이 블록의 슬라이드</a>

## 목표

로컬 커밋과 원격 저장소를 구분하고, 변경을 GitHub에 올려 결과를 확인합니다.

## 3시간 진행

- 1교시: GitHub 저장소를 만들고 로컬 저장소와 연결합니다.
- 2교시: `git push`를 실행하고 웹에서 파일과 커밋을 확인합니다.
- 3교시: Pages의 정적 페이지 공개 흐름을 살펴보고 강사 안내에 따라 설정합니다.

각 교시는 45분 수업과 15분 휴식으로 진행합니다. 계정 정책이나 인증 문제가 있으면 웹 화면 시연과 질문으로 이어갑니다.

## 실습 과제

문구를 한 번 더 바꾸고 커밋·push한 뒤 GitHub 저장소에서 확인합니다.
