# B · GitHub 원격 공유와 Pages

[전체 블록 안내](../) · [상세 명령 안내](../git-guide) · <a href="/git/slides/8">이 블록 슬라이드</a>

## 목표

로컬 Repository와 GitHub Remote를 연결하고 `remote`·`push`·`pull`·`clone`·`fork`를 구분합니다. GitHub Pages의 정적 웹 배포를 확인합니다.

## 3시간 진행

- 1교시: GitHub 저장소 만들기, 원격 주소와 인증 확인
- 2교시: remote 연결, `push` 후 웹에서 파일·커밋 확인
- 3교시: Pages 설정과 배포 주소 확인, 공개 범위 점검

각 교시는 45분 수업과 15분 휴식입니다. 세 번째 수업의 마지막 20분은 아래 과제 15분과 퀴즈 5분으로 둡니다. 설치나 인증이 막히면 강사 시연과 예제 저장소로 이어가며 자기 변경을 확인하게 합니다.

## 실습 과제

문구를 한 번 더 바꾸고 커밋·push한 뒤 저장소와 Pages 결과를 확인합니다.
