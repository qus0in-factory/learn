# D · Branch·병합·Pull Request

[전체 블록 안내](../) · [상세 명령 안내](../git-guide) · <a href="/git/slides/14">이 블록 슬라이드</a>

## 목표

branch·checkout·switch·tag를 살펴봅니다. 기본 브랜치는 `main` 또는 `master`일 수 있습니다. Fast-forward와 3-way merge, conflict, `log --graph`, PR의 목적을 익힙니다.

## 3시간 진행

- 1교시: 새 브랜치에서 작은 변경을 커밋하고 기록 그래프 확인
- 2교시: 강사 시연으로 fast-forward·3-way merge·conflict 살펴보기
- 3교시: 웹 PR 또는 선택적 `gh` 시연, 회고

각 교시는 45분 수업과 15분 휴식입니다. 세 번째 수업의 마지막 20분은 아래 과제 15분과 퀴즈 5분으로 둡니다. 설치나 인증이 막히면 강사 시연과 예제 저장소로 이어가며 자기 변경을 확인하게 합니다.

## 실습 과제

작은 변경을 새 브랜치에서 만들고 짝의 변경을 읽어 PR 설명이나 피드백 한 줄을 작성합니다.

## 퀴즈
