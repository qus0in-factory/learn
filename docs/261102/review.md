# 초안 검토 및 진행 순서 제안

## 교육 방향과 운영 조건

- 대상: Windows 환경에서 코딩 3주차인 Python 기본 문법 학습자.
- **1일차:** OpenCode로 간단한 정적 웹페이지를 만들고 GitHub Pages에 배포하며 Git의 기본 흐름을 익힌다.
- **2일차:** 배포한 웹을 각자 확장한다. 눈누 웹폰트, 파비콘, [Coolors](https://coolors.co/) 색상 조합과 콘텐츠 등을 적용하며 같은 출발점에서 서로 다른 결과가 나오는 경험을 한다.
- 매일 오전 3시간, 오후 3시간을 운영한다. 45분 수업과 15분 휴식을 3회씩 반복하므로 이틀간 실제 수업은 9시간이다. 별도의 여유 시간 2시간은 설치·인증·배포 문제와 질문에 사용한다.
- 코드와 문서의 생성·수정은 OpenCode에 요청한다. 학습자는 변경 결과를 읽고 브라우저에서 확인하며, Git의 핵심 명령은 Git Bash에서 직접 실행한다.
- 첫 시간에 설치를 시작하고 다운로드·설치 중 PPT로 VCS, Git과 GitHub, 작업 디렉터리·스테이징·저장소를 설명한다.

## 초안의 적절성

학습자가 변경한 웹을 직접 배포하고 다시 개선하는 흐름은 Git과 GitHub의 쓰임을 이해하기에 적절하다. 다만 실제 수업 9시간에 초안의 모든 명령과 기능을 익히기는 어렵다. 배포와 변경 반영을 반복하는 데 우선순위를 두고, 협업 기능은 여건에 맞춰 간단히 경험한다.

- **공통 필수:** `config`, `init`, `status`, `add`, `commit`, `log`, `.gitignore`, GitHub 원격 연결과 `push`, Markdown·README, GitHub Pages 배포 및 변경 반영.
- **시간에 맞춰 소개:** `clone`, `pull`, 브랜치, Pull Request, Issue. 둘째 날 변경을 브랜치에서 진행하거나 시연한다.
- **후속 학습:** `reset`, `amend`, `revert`의 상세 비교, vi와 해시, `.gitkeep`, fork, tag, 병합 방식의 내부 원리, Label·Milestone·Wiki, GitHub CLI와 ChatGPT GitHub 플러그인.

처음 웹은 빌드 과정이 없는 HTML·CSS·JavaScript 정적 페이지로 제한한다. OpenCode에 작은 변경을 하나씩 요청하고, 생성 결과와 Git 변경 내용을 확인한 뒤 커밋한다. 눈누 폰트는 선택한 폰트의 사용 범위와 웹 적용 안내를 확인한다. 파비콘은 직접 만든 이미지나 사용이 허용된 파일을 사용한다. Pages 배포 시 저장소 경로를 고려해 폰트·이미지·파비콘이 실제 배포 주소에서도 표시되는지 확인한다.
