## 목표

작은 디자인 변경을 요청하고 사용 조건과 결과를 직접 확인합니다.

## 3시간 진행

- 1교시: 폰트·색상·소개 문구 중 바꾸고 싶은 부분을 고릅니다.
- 2교시: 에이전트에게 작은 수정을 요청하고 브라우저와 변경 파일을 비교합니다.
- 3교시: 외부 폰트·아이콘·이미지의 출처와 이용 조건을 확인하고 변경을 기록합니다.

각 교시는 45분 수업과 15분 휴식으로 진행합니다. 설치가 준비된 학습자는 폰트나 파비콘을 적용하고, 아니면 색상·문구 변경으로 진행합니다.

## 실습 과제

색상 또는 소개 문구를 바꾸고 커밋·push합니다.

## 퀴즈

1. 외부 폰트를 사용하기 전에 무엇을 확인해야 하나요?
2. 에이전트가 고친 파일은 어떻게 확인하나요?
