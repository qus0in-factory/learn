# D · 협업 맛보기

[전체 블록 안내](../) · <a href="/git/slides/14">이 블록의 슬라이드</a>

## 목표

브랜치와 Pull Request가 변경을 나누고 검토하는 방법임을 이해합니다.

## 3시간 진행

- 1교시: 브랜치와 Pull Request의 역할을 사례로 살펴봅니다.
- 2교시: 짝 리뷰 또는 강사 시연으로 변경 요약을 읽고 의견을 나눕니다.
- 3교시: 준비된 경우 `gh`로 PR을 살펴보고, 배포 결과와 학습 내용을 정리합니다.

각 교시는 45분 수업과 15분 휴식으로 진행합니다. GitHub CLI 설치와 인증은 선택이며, 웹 화면으로도 협업 흐름을 익힐 수 있습니다.

## 실습 과제

다른 사람의 변경을 읽고 질문 또는 피드백 한 줄을 남깁니다.
